Privacy Policy

This privacy policy applies to the LocalGemmaChat app for iPhone (the “Application”), operated by BIN XIAO (the “Service Provider”).

Your data stays on your device. LocalGemmaChat runs the AI model entirely on your iPhone. There are no accounts, no ads, no analytics, no telemetry, no crash-reporting SDKs, no third-party tracking, and no in-app purchases. The Application never sends your conversations, prompts, or model outputs to the Service Provider or to anyone else.

1. Data we do not collect

The Service Provider does not collect, store, transmit, sell, or share any personal data. Specifically, the Application has no functionality to:

  • create or sign in to an account;
  • collect analytics, usage statistics, or crash reports;
  • display advertising or use advertising identifiers (IDFA);
  • access your contacts, photos, microphone, camera, location, or health data;
  • track you across apps or websites;
  • process payments — the Application contains no purchases or subscriptions. All features are free.

Because no data is collected, there is nothing for the Service Provider to access, correct, sell, or delete on its side.

2. Network access

The Application makes network requests for exactly two purposes, both related to obtaining the on-device AI model:

2.1 Model download

On first use, the Application downloads the AI model files (about 2.5 GiB) from Hugging Face. The default download host is hf-mirror.com, an independent third-party mirror of the Hugging Face Hub. You can switch the source to huggingface.co at any time from the HF Source menu inside the Application.

As with any download, the host you connect to can see your IP address and the standard request metadata (such as user agent). Those hosts operate under their own privacy policies, which the Service Provider does not control. No information about you is added to these requests by the Application.

2.2 Model metadata

Before downloading, the Application retrieves the model’s file list and file sizes from the same host so it can show you the total download size and ask for confirmation.

The Application works fully offline after the model has been downloaded. No part of your conversation, and no usage information, is transmitted at any time — including while you are chatting. You can verify this by enabling Airplane Mode after the download completes; the Application continues to work normally.

3. Data stored on your device

The following items are written to the Application’s private storage area on your iPhone. They are readable only by the Application, are never uploaded, and are removed when you delete the Application.

WhatWherePurpose
Model weights and a small metadata file (.filesmeta) Documents/.localllmclient/huggingface/models/… (marked as excluded from iCloud/iTunes backup) Running the AI model offline, and verifying that a download completed
Conversation history: one JSON file and one human-readable Markdown log per model Application Support/LLMclient/History/ Restoring your chat when you reopen the Application, and providing the Markdown export
One preference: whether “Thinking” mode is on System UserDefaults (key thinkingEnabled) Remembering your setting between launches
Memory diagnostics log (diagnostics.log, automatically capped at 512 KB) Documents/diagnostics.log Recording on-device memory usage per reply, so abnormal terminations caused by iOS memory limits can be diagnosed

All AI processing — tokenizing your prompt, running the model, and generating the reply — happens locally on your iPhone’s hardware. Nothing is sent to a cloud service. The diagnostics log contains only numeric memory measurements and the model identifier; it is never transmitted anywhere.

4. Third-party components and model license

The Application includes the following open-source components, all of which run locally on your device and none of which collect data on behalf of the Service Provider:

  • MLX / mlx-swift (Apple) — on-device machine-learning runtime.
  • llama.cpp — local inference library.
  • swift-transformers and swift-jinja (Hugging Face) — model file handling and chat-template rendering.

The bundled model is Gemma 4 E2B Instruct (a text-only 4-bit variant published on Hugging Face as over-show/gemma-4-e2b-it-text-only-4bit), which is distributed under Google’s Gemma Terms of Use. If you use the model’s outputs, those terms, together with Google’s Gemma Prohibited Use Policy, apply to you as an additional agreement between you and Google. The Service Provider is not affiliated with, endorsed by, or sponsored by Google.

5. AI-generated content

Replies are generated by a small on-device language model and may be inaccurate, incomplete, outdated, or inappropriate. Do not rely on them for medical, legal, financial, safety-critical, or other professional advice. Approximately the last two messages of your conversation, together with a fixed system instruction, are provided to the model each turn, so the model may not remember earlier parts of a long conversation.

6. Children

The Application is not directed at children. The Service Provider does not knowingly collect any information from children, because it does not collect information from anyone.

7. Your control over your data

  • Clear Chat (in the “…” menu) erases the current conversation and deletes its history files from your device.
  • Deleting a model (model menu → DEL …) removes the downloaded model files and that model’s stored history, freeing about 2.5 GiB.
  • Deleting the Application removes all of the above from your iPhone.

Since nothing is ever uploaded, there is no server-side copy to remove.
